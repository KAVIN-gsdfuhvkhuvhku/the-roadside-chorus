Habitat Fragmentation:
A sliding puzzle game built with Godot Engine 4, demonstrates habitat fragmentation.
How It Works:
The Goal: Rearrange the shuffled habitat fragmentation tiles on the grid back into their original, correct order.
Mechanics: splits into Easy (3×3, 9 tiles) and Hard (4×4, 16 tiles), both noting the 1,000-move solvable shuffle.
Controls: splits into Easy (empty = Tile 9) and Hard (empty = Tile 16).
